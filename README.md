## `01 // PROJECT_OVERVIEW`

Sistema de cadastro de usuários desenvolvido em **Python**, com menu interativo executado diretamente no terminal.

O projeto foi desenvolvido para praticar lógica de programação, estruturas de dados, entrada de informações e organização de operações em uma aplicação de linha de comando.

---

## `02 // FEATURES`

- **Cadastrar usuário** — nome, idade e e-mail
- **Listar usuários** — visualização dos registros cadastrados
- **Buscar usuário** — pesquisa por nome
- **Menu interativo** — navegação simples pelo terminal
- **Estruturas de dados** — utilização de listas e dicionários
